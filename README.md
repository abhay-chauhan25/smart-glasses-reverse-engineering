# Smart Glasses Reverse Engineering

This repository documents my reverse engineering of [DEVICE NAME/MODEL] AI smart glasses. It is a documentation repo: notes, findings, and reference material, not a product or a finished tool.

## Goals
- Understand how the hardware is built (SoC, sensors, camera, audio, battery)
- Analyze the firmware and companion app
- Document communication protocols (BLE, Wi-Fi, cloud APIs)
- Learn how the AI features work (voice, vision, data flow)
- Share findings so others can build on them

## What's inside
- `hardware/`: teardown photos, chip IDs, pinouts, schematics
- `firmware/`: extraction methods, analysis notes, structure
- `protocols/`: BLE/Wi-Fi/API traces and message formats
- `app/`: companion app analysis
- `tools/`: scripts and helpers used in the research
- `notes/`: logs, open questions, dead ends

## Status
Work in progress. Findings may be incomplete or wrong, so verify before relying on them.

This research is for education and interoperability only. It is not affiliated with or endorsed by the manufacturer. Don't use it to violate laws, terms of service, or other people's privacy. No proprietary firmware or keys are included.
